# Shardelix 15.0.0

Research release focused on real document evidence, damaged fragment
rigid-pose verification, transparent confidence, and reproducible evaluation.

- Recognize sparse neutral documents without OCR; rectify observed pixels
  using mask-aware row interpolation.
- Apply reliable vertical alignment to the output while preserving canvas
  resource limits, and export provisional strip components at weak seams.
- Refine eroded-contour poses using bounded observed-pixel checks and a
  physical lost-boundary gap constraint.
- Corroborate component merges using independent anchors and collision
  checks; keep unsupported components separate.
- Evaluate anonymized DAFNE cases, actual physical strip matching, orientation
  and relative scan alignment. Introduce frozen benchmark manifests.
- Add standard portable wheel and optional C++20 platform wheel packaging
  and a Linux/macOS/Windows installation matrix.

See the [technical report](../TECHNICAL_REPORT.md) for the paired evaluation,
limitations and remaining research checklist. This is not a claim of a
general solution or state-of-the-art performance.

## Local verification

- Native C++ backend: 150 algorithm tests passed.
- Python fallback: 144 passed, six native-only tests skipped.
- Static web/evaluator workflow: 2 tests passed, including shared engine module imports.
- Studio HTTP integration: generation, blind ZIP, continuous/missing replay,
  unsafe-archive rejection and cancellation passed.
- Linux CPython 3.12: built a portable wheel and a native platform wheel;
  installed both into separate directories outside the repository, verified
  version 15.0.0, backend selection, CLI help and 16-piece blind grid demo. Other OS wheel builds
  and actual WASM runtime execution are covered by CI, not local claims.
- Frozen manifest mechanical smoke and resume run completed.
