# Shardelix 15.0.1 — framework maintenance

This patch keeps the V15 solver and evaluation protocol, focusing on reliable
installation, output publication and diagnostic tooling. No new accuracy or
performance improvement is claimed over [V15.0.0](v15.0.0.md).

- The public result export and file reconstruction stage their output before
  publication; existing non-empty output directories are rejected.
- Result diagnostics report placements outside the renderable canvas.
- Process peak RSS uses platform-specific units; unavailable measurements,
  including browser-worker RSS, are represented by null.
- `shardelix doctor` reports the active backend, dependencies and resource
  budget; `shardelix --version` identifies the installed version.
- CI checks native and Python fallback regression, selected static errors,
  combined branch coverage and wheel installation. Releases include the
  portable Python distribution alongside source and Web Studio archives.

The physical-scan, missing-edge and severe-erosion limitations remain
documented in the [technical report](../TECHNICAL_REPORT.md). This is still
an alpha research framework, not a certified production system.
