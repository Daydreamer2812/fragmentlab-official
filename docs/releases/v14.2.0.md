# Shardelix 14.2.0 — classical recovery of damaged fragments

## Changes

The existing blind irregular reconstruction route now uses a hypothesis-only
multi-radius morphological offset of curved fragment contours. No new public
solver, ML model, OCR, reference image or synthesized output pixels.

- Search four scale-dependent dilation radii when the legacy gap route is
  not selected and exact-contact evidence is sparse or mostly weak. Match
  complementary curves on temporary masks, then restore measured crop
  coordinates exactly.
- Verify the proposed rigid pose using original mask overlap, opposing
  tangents, contiguous observed-boundary support, gap and its dispersion.
- Require independently correlated variations and first differences in the
  predicted mid-gap ribbon, nontrivial texture and shape bending. Compare
  competing distinct poses on both original arcs.
- Bound the additional exhaustive work by pair count across all radii and
  estimated memory; the existing sparse/rounded continuation remains available.
- For coherent rounded populations, reject weak seeds with contradictory
  bridge evidence (unless multiple independent line exits corroborate the
  seam). Keep their hypotheses in the competition set.
- Only one final component graph is exported. Unanchored components remain
  independent; no hypothetical expanded material is rendered.

## Measurements (native, blind)

Same 11 development fixtures from `benchmark_classical.py`. The evaluator
applies a 10 px / 10° relative-pose tolerance to accepted seams after solving.
There is no credit for unanchored singleton pieces.

| Erosion | V14.1.0 correct/accepted | V14.2.0 correct/accepted |
|---|---:|---:|
| 3 px (3 cases) | 18/18 | 18/18 |
| 5 px (5 cases) | 12/26 | 15/15 |
| 8 px (3 cases) | 0/17 | 6/6 |
| **Total** | **30/61 (49.2%)** | **39/39 (100%)** |

One four-genuine-piece case at 5 px erosion accepts only one correct seam,
versus two correct (of four accepted) previously. The new route favors
precision over speculative global placement; not every case improves recall.

Additional four seeded cases, with continuous rotations, opaque anonymized
IDs, erosion and distractor: 0/25 → 7/10 correct/accepted. These are synthetic
stress tests from the same fixture family, not independent real-world data.
No claim of complete reconstruction, SOTA, or universally better performance.
The extra bounded search may increase CPU time.

### Severe rounded DAFNE cases

Real scans remain much harder than curved synthetic pieces. On the same
anonymized Resurrection 102 upload (87 genuine pieces, 15 distractors), a
fresh paired run preserves 6 correct relative joins while removing one
false join: 6/13 (46.2%) → 6/12 (50%). Primary recovery remains 3/87.
The Masaccio 101-fragment variant (case 16.30.25) still has **zero** correct
relative joins. Compared with the previously recorded rounded-selection
baseline, false joins decrease from 11 to 8, but there is no recovery gain.
No source image was used. Ground truth was read only after reconstruction.
These two cases were used in previous development and are not held-out.
