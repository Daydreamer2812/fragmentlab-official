# Shardelix 14.1.0 — blind physical document scans

This release improves the existing geometry-specific document strip route,
without adding another solver family, model, OCR system or UI. The legacy
public Python API, CLI, native extension and web workflow are unchanged.
Reference images and evaluation labels remain excluded from blind matching.

## Matching improvements

- Estimate a spatially varying paper background with grayscale morphology;
  remove it from patch evidence, not exported pixels.
- Estimate small vertical displacements using a robust consensus of normalized
  text-row projections. Abstain on weak evidence or near-zero registration.
- Combine shift-tolerant normalized foreground mismatch (30%) with observed
  interior patch recurrence (70%). Reuse identical blank query results.
- Enable the outer paper margin prior only when both sides provide near-white
  margin evidence. Do not assume every scan contains page margins.
- Refine the candidate chain with sparse directed mixed-integer optimization,
  enforcing one connected path via subtour cuts. The Balanced budget is 1.5 s
  (8 candidate neighbors per side), High accuracy 3 s (12); keep the original
  feasible chain if a better objective cannot be found. This is not a guarantee
  of optimal truth ordering.
- Fast mode retains the cheaper existing path. Scan rectification and original
  raster rendering remain separate from matching evidence; no missing text
  is generated. Diagnostics record registration, margin use and path status.

## Paired development-set evidence

Three real physical DocDataset pages, same anonymous pixels and foreground
masks, profile Balanced. Order labels are read only after inference.
Undirected seams count either neighboring orientation; exact positions
also require the correct order and position.

| Case | V14.0.1 seams | V14.1.0 seams | V14.1.0 exact positions |
|---|---:|---:|---:|
| real1_27 | 17/26 | 20/26 | 14/27 |
| real2_56 | 50/55 | 55/55 | 56/56 |
| real3_39 | 23/38 | 34/38 | 22/39 |
| **Total** | **90/119 (75.6%)** | **109/119 (91.6%)** | **92/122** |

Directed correct seams: 88/119 → 109/119. Wrong adjacencies: 29 → 10.

Eight deterministic synthetic stress cases (20–48 strips) use composed
DocDataset crops, uneven widths, shadows, small vertical shifts, random
quarter-turns, noise and wavy/eroded edges. Undirected seams improve from
42/248 (16.9%) to 77/248 (31.0%), but extreme corruption remains unsolved.
These are development tests, not independent held-out data or a SOTA claim.
The full report includes per-case counts and illustrative native timings; the
extra work can cost more CPU. A narrower patch experiment was rejected because
it degraded several stress cases. No accuracy or speed claim is made for arbitrary
uploads, irregular torn pages or browser hardware.

## Reproduce

Download the [original DocDataset archive](https://people.tamu.edu/~xinli/DocReassembly/data/DocDataset.zip)
separately. Raw images are not redistributed.

```bash
PYTHONPATH=src python benchmarks/benchmark_scanned_strips.py DocDataset.zip --out real.json
PYTHONPATH=src python benchmarks/benchmark_scan_stress.py DocDataset.zip --out stress.json
```
